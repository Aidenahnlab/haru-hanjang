- **스택:** 프로토타입 — Vite + React + TypeScript + Tailwind CSS · 아이콘 Lucide(`lucide-react`) · 글꼴 Pretendard, Noto Serif KR
  - 이유: 첫 버전은 가입 없이 이 기기 브라우저에만 저장하고, 오늘의 한 줄도 앱 안 목록에서 고르므로 숨길 키가 없음
- **데이터:** 할 일은 처음부터 진짜로 브라우저에 저장(새로고침해도 남게). 첫 장엔 예시 할 일을 넣지 않음(D-019). 오늘의 한 줄은 앱 안의 명언 목록 30개에서 날짜마다 하나
- **흉내만 낼 것:**
  - 저장 실패(사생활 보호 모드·저장 공간 가득) — 주소 끝에 `?save=fail`을 붙여 열면 저장이 막힌 것처럼 동작
  - 날짜·시각 — 주소 끝에 `?now=2026-10-17T08:00`을 붙이면 그 시각부터 시계가 흐르는 것처럼 동작(다음 날 아침, 며칠 뒤, 자정 직전을 기다리지 않고 열어 보려고)
  - 밤에 내일로 보내기(F3를 만들기 전까지) — 주소에 `&sent=1`을 붙이면 지난 장의 남은 일을 밤에 보낸 것으로 친다 — 03 묶음 조각 3에서 진짜 보내기로 바꾸고 지운다
- **이번엔 안 함:** 할 일 끌어서 순서 바꾸기, 다른 칸으로 옮기기, 종이 고르기, 지난 장 넘겨보기(F4), 하나씩 골라 보내기·낮에도 보내기, 기기 간 이어쓰기, 알림, 한 줄 일기·명언 모으기, 자동 넘기기, 한 달 모아보기
- **옮길 때 다시 볼 것** (Next.js로 옮기면 서버로 가야 하는 것): 지금은 없음 — 서버로 보내는 데이터도 숨길 키도 없음. 기기 간 이어쓰기를 붙일 때 할 일 저장이 여기에 들어옴
