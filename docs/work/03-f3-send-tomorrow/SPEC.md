# 03 · F3 남은 일 내일로 보내기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F3, F2 · 조각 3개
> 정해둔 것: ../SETUP.md

- [x] **1. 저녁의 남은 일 한 줄과 [내일로 보내기]** (F3 ①②)
  - 확인: 그지 않은 일 2개를 두고 `?now=`로 저녁 7시에 열면 장 맨 아래에 "남은 일 2개가 있어요." [내일로 보내기]가 보이고, 낮 2시에 열면 보이지 않는다
  - 확인: [내일로 보내기]를 누르면 그 줄이 "남은 일 2개는 내일 같은 칸에 옮겨 둘게요."로 바뀌고, 보낸 일은 제자리에 흐리게 남아 끝에 "내일로"가 붙고, "내일 장으로 보냈어요." [되돌리기]가 보인다
  - 확인: [되돌리기]를 누르면 "내일로"가 사라지고 [내일로 보내기]가 다시 보인다
- [x] **2. 보낸 뒤에 바뀌는 것들** (F3 예외, 빈 상태)
  - 확인: 보낸 뒤 새 할 일을 하나 적으면 "남은 일 1개가 있어요." [내일로 보내기]가 다시 보인다
  - 확인: 보낸 일을 톡 눌러 그으면 "내일로"가 사라진다
  - 확인: 적은 일을 모두 그으면 장 맨 끝에 "오늘 장, 다 그었어요 ✨ 가지런히 남겨 둘게요."가 보인다
  - 확인: `?save=fail`로 보내면 "방금 보낸 할 일을 저장하지 못했어요. 잠시 후 다시 보내 주세요."가 보이고 보낸 모습은 남아 있다
- [ ] **3. 다음 날 진짜로 받기** (F3 → F2 ①)
  - 확인: 밤에 오전 "은행 들르기"를 보내고 `&sent=1` 없이 다음 날 아침에 열면 오전 칸 맨 위에 "은행 들르기"가 있고 "오늘 장이 준비됐어요 ☀️ 어제 넘긴 일 1개가 기다리고 있어요!"가 보인다
  - 확인: 보낸 일 1개와 보내지 않은 일 1개를 두고 다음 날 열면 넘긴 일은 칸에 와 있고, "어제 장에 남은 일 1개가 있어요." [오늘 장에 옮기기]도 보인다
  - 확인: 주소에 `&sent=1`을 붙여도 보내지 않은 일은 넘어오지 않는다(흉내가 지워짐)
