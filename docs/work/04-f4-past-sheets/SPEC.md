# 04 · F4 지난 장 넘겨보기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F4 · 조각 3개
> 정해둔 것: ../SETUP.md

- [x] **1. [지난 장 넘겨 보기]와 지난 장 한 장** (F4 ①②)
  - 확인: 전날 장이 있는 날 오늘 장을 열면 날짜 위에 [지난 장 넘겨 보기]가 보이고, 이 기기의 첫 장에서는 보이지 않는다
  - 확인: [지난 장 넘겨 보기]를 누르면 전날 날짜와 그날의 한 줄이 놓인 지난 장 카드가 보이고, 그어 둔 줄이 그대로 있다
  - 확인: [오늘 장으로]를 누르면 오늘 장으로 돌아온다
- [x] **2. 읽기만 하는 기록** (F4 ②, 빈 상태)
  - 확인: 지난 장의 할 일을 눌러도 줄이 그어지거나 풀리지 않고, 길게 눌러도 메뉴가 뜨지 않는다
  - 확인: 밤에 보낸 일은 흐리게 "내일로"가 붙어 있고, 아침 인사·남은 일 줄·보내기 줄은 보이지 않는다
  - 확인: 적은 일이 없는 지난 장에서는 "이 장엔 적어 둔 할 일이 없어요."가 보인다
- [x] **3. 한 장씩 넘기기** (F4 ②, 예외)
  - 확인: 16일·18일·20일 장이 있고 오늘이 20일이면, [지난 장 넘겨 보기] → 18일, [‹ 이전 장] → 16일로 넘어간다(17일은 건너뜀)
  - 확인: 가장 오래된 16일 장에서는 [‹ 이전 장]이 보이지 않고, [다음 장 ›]을 누르면 18일로 간다
  - 확인: 18일 장에서는 [다음 장 ›]이 보이지 않고, [오늘 장으로]를 누르면 20일 오늘 장으로 돌아온다
