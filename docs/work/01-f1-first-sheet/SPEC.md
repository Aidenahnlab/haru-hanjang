# 01 · F1 첫 장에 적고 긋기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F1 · 조각 4개
> 정해둔 것: ../SETUP.md

- [x] **1. 프로젝트 준비 + 빈 오늘 장** (F1 ①)
  - 확인: 처음 열면 맨 위에 오늘 날짜(예: "10월 16일 금요일")와 오늘의 한 줄·지은이가 보인다
  - 확인: "오늘 장을 펼쳐 두었어요. 칸을 톡 눌러 적어 보세요."와 새벽·오전·오후·밤 4칸이 세로로 보인다
  - 확인: 데스크톱 폭에서 열면 노트 한 장이 화면 가운데 폰 폭으로 놓인다
- [x] **2. 칸에 적기** (F1 ②)
  - 확인: 오후 칸을 누르면 "오후에 할 일을 적어 두세요."가 적힌 입력줄이 열리고, 적고 엔터를 치면 할 일이 적히고 아래에 다음 입력줄이 열린다
  - 확인: 빈 입력줄에서 엔터를 치면 입력이 닫히고, 엔터 없이 칸 바깥을 누르면 적던 글이 할 일로 남는다
  - 확인: 할 일을 적고 새로고침해도 같은 칸에 그대로 있다
  - 확인: 주소 끝에 `?save=fail`을 붙여 열고 적으면 "방금 적은 할 일을 저장하지 못했어요. 잠시 후 다시 적어 주세요."가 보이고, 적은 글은 화면에 남는다
- [x] **3. 톡 눌러 긋기 + 첫 긋기 한마디** (F1 ③④)
  - 확인: 할 일을 톡 누르면 펜 선이 왼쪽에서 오른쪽으로 그어지고, 그은 할 일은 제자리에 흐리게 남는다
  - 확인: 처음 그었을 때만 화면 아래에 "그은 줄은 지우지 않고 남겨 둘게요." [되돌리기]가 잠깐 뜨고, 두 번째부터는 뜨지 않는다
  - 확인: 그은 할 일을 다시 톡 누르거나 [되돌리기]를 누르면 줄이 풀린다
- [ ] **4. 길게 눌러 고치기·지우기** (F1 ③, 예외)
  - 확인: 할 일을 길게 누르면 [고치기] [지우기]만 있는 작은 메뉴가 뜨고, [고치기]로 글을 바꿀 수 있다
  - 확인: [지우기]를 누르면 묻지 않고 바로 지워지고 "할 일을 지웠어요." [되돌리기]가 잠깐 보이며, [되돌리기]를 누르면 제자리에 돌아온다
  - 확인: 아주 긴 할 일은 잘리지 않고 줄을 바꿔 다 보인다
