# 02 · F2 아침에 새 장 펼치기

> Vibe Studio · build-spec · 작성일: 2026-10-16
> 목표: UI 구현 · 관련 플로우: F2 · 조각 4개
> 정해둔 것: ../SETUP.md

- [x] **1. 날짜가 바뀌면 새 장 + 아침 인사** (F2 ①)
  - 확인: 오늘 할 일을 적고 `?now=`로 다음 날 아침에 열면, 새 날짜와 다른 오늘의 한 줄이 놓인 빈 장이 보이고 "새 장이 펼쳐졌어요 ☀️ 오늘의 한 줄도 바뀌었어요."가 보인다
  - 확인: 다시 `?now=`로 전날에 열면 전날 장에 적어 둔 할 일이 그대로 있다
  - 확인: 브라우저 데이터를 지우고 다음 날로 열면 F1 첫 장처럼 "오늘 장을 펼쳐 두었어요. 칸을 톡 눌러 적어 보세요."가 보인다
- [x] **2. 넘긴 일 받기** (F2 ①②)
  - 확인: 오전 칸에 "은행 들르기"를 남기고 `&sent=1`로 다음 날 열면, 오전 칸 맨 위에 "은행 들르기"가 있고 "오늘 장이 준비됐어요 ☀️ 어제 넘긴 일 1개가 기다리고 있어요!"가 보인다
  - 확인: 넘긴 일을 톡 누르면 줄이 그어지고, 첫 긋기 한마디는 나오지 않는다
  - 확인: 사흘 뒤로 열면 "오늘 장이 준비됐어요 ☀️ 지난 장에서 넘긴 일 1개가 기다리고 있어요!"가 보인다
- [x] **3. 남은 일 한 줄 챙기기와 옮기기** (F2 ①)
  - 확인: 어제 장에 그지 않은 일 2개를 두고(보내지 않음) 다음 날 열면 "어제 장에 남은 일 2개가 있어요." [오늘 장에 옮기기]가 보인다
  - 확인: [오늘 장에 옮기기]를 누르면 두 일이 같은 칸 맨 위로 오고 "남은 일 2개를 오늘 같은 칸에 옮겨 두었어요." [되돌리기]가 보이며, [되돌리기]를 누르면 빠지고 남은 일 줄이 다시 보인다
  - 확인: 옮기지 않고 오늘 장에 하나를 적으면 남은 일 줄이 조용히 접힌다
  - 확인: `?save=fail`로 옮기면 "방금 옮긴 할 일을 저장하지 못했어요. 잠시 후 다시 옮겨 주세요."가 보이고 옮긴 모습은 남아 있다
- [ ] **4. 켜 둔 채 자정이 지나면** (F2 예외)
  - 확인: `?now=`로 자정 1분 전에 열어 두고 1분 넘게 보고 있어도 장이 바뀌지 않는다
  - 확인: 자정이 지난 뒤 다른 탭에 갔다가 돌아오면 다음 날 새 장이 펼쳐져 있다
