Voice

하루한장

아침마다 새 종이를 펼쳐 두고, 밤에는 남은 일을 가지런히 챙겨 두는 다정한 집사의 노트

확정 이름 2026-10-16
Summary

이렇게 말해요

다정한 집사처럼 말해요. 나서지 않고 조용히 챙기다가, 꼭 필요한 순간엔 정중하고 너그러운 한마디로 하루를 가지런히 정돈해 줘요.

Traits

핵심 성격

정중한

우리는
"~해요"체로 예의 있게, 하지만 이웃에게 말하듯 편안하게 말해요.
우리가 아닌 것
호텔 컨시어지처럼 격식 차린 서비스업 말투, "주인님"처럼 집사 콘셉트를 연기하는 과잉 의전.

“오늘 장이 준비됐어요 ☀️ 어제 넘긴 일 1개가 기다리고 있어요!”

“고객님, 오늘의 일정을 확인해 드리겠습니다.”

조용한

우리는
말은 적게, 화면은 종이처럼 비워 두되 칸을 다 그었을 때·문제가 생겼을 때처럼 중요한 순간엔 꼭 한마디 건네요.
우리가 아닌 것
아무 반응 없는 무심함, 단어만 툭 던지는 끊긴 말투.

“오늘 장, 다 그었어요 ✨ 가지런히 남겨 둘게요.”

“2개 남음.”

너그러운

우리는
다 못 한 날도 탓하지 않고, 남은 일은 내일 같은 칸으로 조용히 옮겨 줘요.
우리가 아닌 것
채근하거나 겁주는 말, 점수·연속 기록으로 몰아붙이는 동기부여.

“어제 보낸 일 하나, 오전 칸에 옮겨 두었어요.”

“앗, 아직 2개 남았어요! 😢 내일은 꼭 끝내봐요 💪”

Vocabulary

어휘

쓰는 말

  • 장 / 오늘 장 / 새 장하루 한 장의 종이. 날짜·페이지 대신 쓴다.
  • 칸 (새벽·오전·오후·밤 칸)시간대를 부르는 말. "세션", "시간 블록" 대신.
  • 적다 / 적어 두다할 일을 넣을 때. "추가", "등록" 대신.
  • 긋다 / 그었어요끝낸 일. "완료", "체크" 대신 종이의 손맛을 살린다.
  • 내일로 보내기 / 옮겨 두었어요못 한 일을 넘길 때. 실패가 아니라 정리로 들리게.
  • 남겨 둘게요 / 넣어 둘게요기록이 사라지지 않는다는 안심을 줄 때.
  • 준비됐어요 / 펼쳐 두었어요아침에 새 장을 열 때. 미리 챙겨 둔 집사의 느낌.
  • 기다리고 있어요어제 넘긴 일을 알려줄 때. 재촉이 아니라 반가움으로.
  • 가지런히정돈된 느낌을 줄 때. 다 그은 장, 지난 장 정리에.
  • 넘겨 보기 / 지난 장기록을 볼 때. "히스토리", "아카이브" 대신.
  • 할 일항목을 부르는 말. "태스크", "투두" 대신.
  • 오늘의 한 줄명언을 부를 때. 말은 붙이지 않고 문장만 둔다.

피하는 말

  • 고객님 / 주인님 / 분부격식 차린 서비스업 말투, 콘셉트 연기라서.
  • ~드리겠습니다 / ~하시겠습니까?호텔 컨시어지처럼 거리감이 생겨서.
  • 태스크 / 투두 / 싱크 / 리마인더영어·업계 용어라서. 우리말로 쓴다.
  • 스트릭 / 연속 기록 / 🔥 N일째게임식 동기부여라서.
  • 배지 / 레벨 / 달성 보상종이에는 점수가 없어서.
  • 달성률 / N% / 목표 미달성하루를 평가하는 말이라서.
  • 꼭 / 반드시 / 놓치지 마세요채근하는 말이라서.
  • 사라져요 / 지금 안 하면겁주는 말이라서.
  • 정말 ~하시겠어요? / 저장할까요?계속 묻지 않는다. 바로 실행하고 되돌리기만 열어 둔다.
  • 분발하세요 / 힘내세요 💪몰아붙이는 응원이라서.
  • 당신의 속도대로 / 이미 충분해요 🌿위로가 과해 오글거리는 힐링 에세이 톤이라서.
  • 완료 / 미완료기계적인 상태 표시라서. "그었어요", "남은 일"로.
  • "2개 남음." 같은 단어 끝맺음너무 짧아 무심하게 들려서.
Context

상황별 톤

맥락톤 조절예시 문구
온보딩 / 첫 화면정중함 유지, 설명은 최소로. 배울 것 없이 바로 적게 한다"오늘 장을 펼쳐 두었어요. 칸을 톡 눌러 적어 보세요."
빈 상태(empty state)조용함을 가장 크게. 한 문장으로 권하기만 한다"오후에 할 일을 적어 두세요."
성공/완료 피드백다정함을 올리고, 이모지 하나 허용. 기록이 남는다는 안심으로 끝맺는다"오늘 장, 다 그었어요 ✨ 가지런히 남겨 둘게요."
아침 첫 열기밝음을 올린다. 이모지 하나·느낌표 하나 허용, 챙겨 둔 느낌으로"오늘 장이 준비됐어요 ☀️ 어제 넘긴 일 1개가 기다리고 있어요!"
못 한 일 남은 밤너그러움을 가장 크게. 탓하지 않고 옮겨 주는 쪽으로"남은 일 2개는 내일 같은 칸에 옮겨 둘게요."
에러/안내정중함을 올리고 밝음은 내린다. 무엇이 일어났고 무엇을 하면 되는지 온전한 문장으로"방금 적은 할 일을 저장하지 못했어요. 잠시 후 다시 적어 주세요."
푸시 알림최소로 보낸다. 보낼 땐 하루 한 번, 재촉 없이 새 장 소식만"새 장이 펼쳐졌어요 ☀️ 오늘의 한 줄도 바뀌었어요."
랜딩/소개 페이지조용한 자신감. 기능 나열보다 종이 한 장의 감각으로"하루를 네 칸에 적고, 펜으로 긋듯 지워요. 그은 줄은 기록으로 남아요."

정중·조용·너그러움 세 성격은 어느 맥락에서도 사라지지 않는다. 아침과 다 그은 순간엔 밝음을 올리고, 에러에선 밝음을 내리고 정중함을 올리고, 못 한 일 앞에선 너그러움을 가장 크게 한다. 채근과 평가는 어떤 맥락에서도 0이다.

Style

표기 규칙

존댓말/반말
"~해요"체 기본. "~습니다"체와 반말은 쓰지 않는다.
문장 길이
짧게, 하지만 끊지 않는다. 단어만 툭 던지지 않고 온전한 문장으로 끝맺는다.
이모지
아침 첫 열기·다 그은 순간·알림에서만, 한 문구에 최대 1개. ☀️ ✨ 🌙처럼 종이·하루 느낌의 것만 쓰고 💪 🔥 😢는 쓰지 않는다.
느낌표
한 문구에 최대 1개. 재촉하는 문장에는 쓰지 않는다.
용어
영어·업계 용어 대신 우리말(할 일·칸·긋기·장·내일로 보내기).
숫자
"2개"처럼 개수까지만. 퍼센트·달성률·점수는 쓰지 않는다.
확인 질문
묻지 않고 바로 실행한다. 잘못 그었을 때 되돌리기만 조용히 열어 둔다.
오늘의 한 줄(명언)
문장만 두고 앞뒤에 설명이나 말을 붙이지 않는다.
Do · Don't

이렇게 쓰고, 이렇게 쓰지 않아요

Do

  • 미리 챙겨 둔 느낌으로 말한다 — "준비됐어요", "옮겨 두었어요", "남겨 둘게요".
  • 중요한 순간(다 그었을 때, 문제가 생겼을 때)엔 꼭 한마디 건넨다.
  • 못 한 일은 탓하지 않고 내일 같은 칸으로 옮겨 주는 말로 정리한다.
  • 아침 인사는 밝게 — 이모지 하나, 느낌표 하나까지.
  • 종이 노트의 말(장·칸·적다·긋다)을 쓴다.
  • 짧아도 온전한 문장으로, 끝에 챙겨 주는 한마디를 붙인다.
  • 읽고 나서 "오늘이 한 장에 정돈됐다"는 기분이 들게 쓴다.

Don't

  • "고객님", "~드리겠습니다"처럼 호텔 컨시어지 말투를 쓰지 않는다.
  • "주인님", "분부만 내려주세요"처럼 집사 콘셉트를 연기하지 않는다.
  • 연속 기록·배지·달성률 같은 게임식 동기부여를 하지 않는다.
  • "꼭", "놓치지 마세요", "사라져요"처럼 채근하거나 겁주지 않는다.
  • 태스크·투두·리마인더 같은 영어·업계 용어를 쓰지 않는다.
  • "정말 완료하시겠어요?"처럼 확인을 계속 묻지 않는다.
  • "2개 남음."처럼 단어만 툭 던져 무심하게 들리게 하지 않는다.
  • 아무 반응 없이 지나쳐 무심해 보이게 두지 않는다.
